# Public tests and fixtures

This directory contains only synthetic smoke fixtures. The historical private regression suite and Human Review outputs remain in the private canonical workspace and are intentionally not copied here.

Run the dependency-free validator from the repository root:

```sh
python3 -I -S -B scripts/validate.py
```

The public demo uses `SYN-*` identifiers, fictional project names and `example.invalid`; it is not candidate evidence.
