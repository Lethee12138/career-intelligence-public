# First Real Source Adapter Selection

## Goal

Select the first real public career source for validating the Official Career Adapter.

The first source is a technical validation target, not a production market scan.

## Selection Criteria

Prefer sources with:

- public career pages
- stable job detail pages
- visible role information
- clear location fields
- no account requirement

Avoid sources requiring:

- login
- private recruiter access
- application submission
- personal data

## Validation Flow

Source page

-> extraction

-> Job Source Record

-> verification

-> Job Scan Candidate

## Candidate Source Order

Phase 1:

- SAP Careers
- Schneider Careers

Phase 2:

- Tencent Careers
- Kuaishou Careers

## Success Criteria

The adapter should produce:

- company
- role
- location
- source URL
- status
- authority level

The adapter should not produce:

- fit decision
- ranking
- application decision
