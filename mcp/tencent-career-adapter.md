# Tencent Career Adapter

## Purpose

Map Tencent official recruitment sources into the common official source runtime.

## Current Stage

Live detail verification is active on the verified official host `join.qq.com`. The adapter resolves a public post-detail URL to Tencent's public read-only job-detail JSON API. Broad Tencent vacancy discovery is not enabled yet. No application action.

## Expected Fields

- company
- role
- post_id
- location
- business_group
- job_description
- requirements

## Verification

Official Tencent source required before OPEN_VERIFIED.

## Boundary

Does not decide:

- candidate fit
- application priority
- CV routing
