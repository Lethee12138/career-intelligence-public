# SAP Real Fetch Prototype

## Purpose

Validate the first real public career source flow.

Flow:

Official SAP Career URL

-> fetch boundary

-> extraction candidate

-> Job Source Record

-> verification

## Scope

Allowed:
- public page retrieval
- source metadata capture
- field extraction

Not allowed:
- login
- application submission
- CV upload
- candidate actions

## Output

Produce a source record only.

The Career Intelligence layer decides fit and routing.
