# Public source boundary

This release workspace contains reusable rules, schemas, workflows, scripts and synthetic examples. It deliberately does not copy local source manifests, attachment paths, conversation IDs, chat provenance, personal Career records, CV sources or application outputs.

Public fixtures are marked `SYNTHETIC` and use `SYN-*` identifiers. They are not evidence, market truth, legal verification or current vacancy data.

When using the toolkit for a real candidate, bind each claim to the caller's private, reviewable source and preserve `UNKNOWN` / `VERIFY` where the source is absent or stale.
