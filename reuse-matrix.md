# Reuse Matrix

This public release records method-level decisions only. No external repository code, assets, dependency or private Career data is bundled.

| Pattern | Decision | Boundary |
|---|---|---|
| Evidence-first source trace | REUSE | Caller-owned private evidence remains the authority. |
| Requirement → evidence → gap | REUSE | Missing input remains UNKNOWN / VERIFY. |
| Broad discovery before selection | REUSE | Opportunity Pool is separate from targeted preparation work. |
| Numeric fit scores and automatic application | DROP | Human review and bounded explanations are required. |
| Personal profile or application tracker in the repository | DROP | Supply private context externally. |

External comparison samples are not included as verified implementations or dependencies.
