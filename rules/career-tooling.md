# Career tooling and method reuse

Human-reviewed method update: 2026-09-19.

Career Intelligence remains the canonical process. External tools, sites and skills may fill a verified gap; they do not replace the existing Evidence First workflow or create a parallel career system.

## Discovery-only source: 来个OC / givemeoc

Treat 来个OC / givemeoc as a secondary job-discovery reference source (二级岗位发现资料源) only. This label is a workflow role, not a claim that it belongs to a numbered authority tier.

Useful for:
- campus / autumn-recruitment discovery
- city coverage gaps
- industry coverage gaps
- company-type filtering
- deadline discovery

Its content may create a Candidate only. Qualification, intended applicant population, live vacancy status, application limits and deadlines require employer-official verification before becoming official Evidence or a confirmed application target.

## Annual China scan timing

Add an annual early scan window for foreign enterprises, consulting and internationalised companies in July–August. Do not wait for the traditional September–October peak.

Third-party recruitment calendars and summaries remain discovery aids. Verify each role against the employer's official recruitment source.

## OfferNow

Treat OfferNow only as a possible future application-form prefill aid. Do not install or invoke it by default.

Potential future use:
- store structured resume data
- maintain multiple resume versions
- parse PDF / DOCX
- prefill repeated recruitment-form fields

Default execution boundary:
automatic prefill → Human check → Human submit.

Never allow unchecked submission of:
- graduation date
- visa / work-right status
- salary
- adjustment / reassignment preference
- assignment / posting preference
- work location
- identity and other important personal information

Current state: reference only; not installed and not used for application execution.

## Skill reuse policy

Previously reviewed ideas may include Agent Reach, Offer Toolkit, PDF / Documents / Interview / Spreadsheets / Skill Creator and similar job-search skills.

Do not install a collection of skills merely because a post recommends them. Use this sequence:

existing Career gap → identify a useful method → borrow the method or add the smallest missing capability.

Reusable method sequence:
job discovery → JD diagnosis → evidence mining → resume tailoring → interview follow-up → application tracking.

All reused methods remain subordinate to:
- current Career process
- Evidence First
- source verification
- Human Review before external action

Do not rebuild a second Career pipeline around external skills.
